Adds [b]Gen 2, Gen 3 and Gen 4[/b] versions of every server to the shop, plus a new switch with both copper and fibre ports.

Late in the game, a big customer means filling rack after rack with the same 3U servers and cabling every one. Next-Gen servers do that job in less space with fewer cables. They cost more money and XP, so the normal servers are still worth buying early on.

[h2]⚠ This is a code mod: check how to install it[/h2]
If you have [b]WorkshopModSync[/b], just subscribe and start the game. If you don't, Data Center won't install code mods by itself, so there's one file to copy. See [b]Install[/b] below. It takes about a minute.

[h2]Before you install (once, for any code mod)[/h2]
If you already use other code mods, you most likely have these. Otherwise:
[olist]
[*][b]MelonLoader 0.7.3[/b] from [url=https://github.com/LavaGang/MelonLoader/releases]the MelonLoader releases page[/url]. Run the installer, point it at Data Center.exe, choose 0.7.3, install. Start the game once, then quit.
[*][b]A fix-up plugin[/b], or no code mods load at all: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3797166996]DS-InteropFix[/url] or [url=https://github.com/mleem97/Il2CppAssemblyFixer]Il2CppAssemblyFixer[/url]. Follow its own instructions.
[/olist]

[h2]Install: easiest, with WorkshopModSync[/h2]
If you have the [b]WorkshopModSync[/b] helper, Workshop mods install themselves:
[olist]
[*]Subscribe to this mod.
[*]Start the game. That's it. WorkshopModSync copies your subscribed mods into place each time the game starts, updates included.
[/olist]
[b]Do I have it?[/b] Open your game folder (Steam Library → right-click [b]Data Center[/b] → [b]Manage[/b] → [b]Browse local files[/b]) and look in the [b]Plugins[/b] folder. If [b]WorkshopModSync.dll[/b] is there, you have it. It's made by another modder and comes with the DhcpMod mod on the Workshop.

[h2]Install: without WorkshopModSync (copy one file)[/h2]
Data Center downloads Workshop mods into a folder of its own, which MelonLoader doesn't look in, so copy the file across once:
[olist]
[*]Subscribe to this mod.
[*]Start Data Center, wait for the main menu, then quit. (The game copies the download into its folder.)
[*]Open your game folder: in your Steam Library, right-click [b]Data Center[/b] → [b]Manage[/b] → [b]Browse local files[/b].
[*]Open [b]Data Center_Data[/b] → [b]StreamingAssets[/b] → [b]Mods[/b].
[*]Find this mod's folder, called [i]workshop_[/i] followed by a long number. The easy way: type [b]NextGenHardware[/b] into File Explorer's search box (top right).
[*]Inside it, open [b]Mods[/b] and copy [b]NextGenHardware.dll[/b].
[*]Go back to the game folder from step 3 (the one with Data Center.exe), open its [b]Mods[/b] folder, and paste.
[*]Start the game. The MelonLoader console shows [b]Next-Gen Hardware v1.0.0[/b], and the shop has "Gen 2", "Gen 3" and "Gen 4" servers.
[/olist]
[b]Had "New Servers"?[/b] That's this mod's old name. Delete [b]NewServers.dll[/b] from your Mods folder. Your unlocks and servers carry over.

[h2]Using Gen 3 and Gen 4 servers[/h2]
Their SFP slots need a module before a cable connects, just like the fibre switches. Buy a box of SFP modules, hold it, click a slot to insert a module, then plug in a cable. Any module type is fast enough. [b]SFP RJ45[/b] takes an ordinary copper cable.

[h2]Saves[/h2]
[list]
[*]Saves stay vanilla. Upgraded hardware is saved as its normal version, and a small [i].newservers.json[/i] file next to the save remembers the upgrades.
[*]Remove the mod and your saves still load: upgrades become normal servers, the new switch becomes a starter switch, and cables in SFP slots are lost (re-cable those servers).
[*]Rack templates don't support upgraded hardware yet.
[/list]

[h2]Co-op[/h2]
[b]Never tested.[/b] It should work in theory, as long as every player has the mod at the same version.

[h2]Updating and uninstalling[/h2]
[list]
[*][b]Update with WorkshopModSync:[/b] nothing to do. The update installs the next time you start the game.
[*][b]Update without it:[/b] Steam downloads updates automatically. With the game closed, copy the new NextGenHardware.dll across again (steps 2–7 of the copy-one-file install).
[*][b]Uninstall:[/b] with the game closed, unsubscribe first (so WorkshopModSync doesn't put it back), then delete NextGenHardware.dll from the game's Mods folder.
[/list]

[h2]Problems?[/h2]
[list]
[*][b]No mods load at all after a game update:[/b] quit and start the game a second time.
[*][b]Still nothing:[/b] check you have the fix-up plugin, and that the DLL is in the Mods folder next to Data Center.exe (not the one inside StreamingAssets).
[*]Report issues on [url=https://github.com/checkersx/data-centre-next-gen-hardware/issues]GitHub[/url], with the file Data Center\MelonLoader\Latest.log.
[/list]
